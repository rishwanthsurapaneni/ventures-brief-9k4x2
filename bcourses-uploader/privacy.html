Privacy policy

bCourses Uploader. Last updated November 5, 2026.

Summary

bCourses Uploader is a personal tool used only by its owner. It copies the owner's own UC Berkeley bCourses materials into the owner's own Google Drive. It does not collect data from anyone else, and it does not share data with anyone.

Google user data the app accesses

The app uses Google's drive.file permission only. With it, the app can create files and folders in the owner's Google Drive and update or read the files it created. It cannot see any other file in that Drive.

How the data is used

The app uses this access only to keep the owner's copy of their course materials up to date. It does not use Google user data for advertising, it does not sell it, and it does not use it to train any AI or machine learning model.

Where data is stored

Course materials are stored in the owner's own Google Drive and on the owner's own computer. The Google sign-in credential is kept in the computer's secure system keychain. No data is sent to any server run by the app, because there is none.

Sharing

The app does not share, transfer or disclose Google user data to any third party.

Deleting data and revoking access

The owner can remove the app's access at any time at myaccount.google.com/permissions, and can delete any file the app created directly in Google Drive.

Contact

Questions about this policy can be sent through github.com/rishwanthsurapaneni.
